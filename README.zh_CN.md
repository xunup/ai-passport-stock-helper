<h1 align="center">AI Passport 股票盯盘</h1>

<p align="center">
  <strong>戴在手腕上的自选股行情板。</strong><br>
  三键操作、设备内设置，以及浏览器配置页。
</p>

<p align="center">
  ESP32-C3 · 8 MB Flash · 240 × 320 屏幕 · 2.4 GHz Wi-Fi
</p>

---

**AI Passport 股票盯盘**是运行在 FoloToy AI Passport 上的独立固件。设备从新浪财经
拉取最多 8 只 A 股、指数或 ETF 的行情，以深色四行列表展示。固件内置配置网页，用于
配网、维护自选股和调整设备设置；屏幕亮度、刷新间隔、自动息屏和配网热点也可以直接在
设备菜单中修改。设备界面与网页均为简体中文。

> 本项目基于 FoloToy AI Passport 基线二次开发，平台文档仍保留在上游目录
> [`docs/`](/docs/README.zh_CN.md) 中。

## 功能

- **实时自选股：**最多 8 只 A 股、指数或 ETF，按刷新档位定时更新（1/3/5/10/15/30/60/120/300 秒，默认 5 秒），也可设为手动、只在按 OK 时刷新；在行情列表中按 OK 可立即刷新。
- **一眼可读：**每屏四行，显示名称、代码、现价、涨跌额与涨跌幅。按国内习惯红涨绿跌；ETF 价格保留三位小数，其他品种保留两位。
- **可选盈亏：**每只自选股可保存成本价与持仓手数；两项都填写后，该行在价格下方以与涨跌幅一致的 12px 样式并列显示 `总:` 持仓盈亏和 `今:` 今日盈亏（例如 `总:+1.23万 今:+560.00`），两者按各自方向着色；未填写的股票不显示。
- **状态栏：**表头用四格信号图标显示 Wi-Fi 强度（按 RSSI 点亮 1–4 格；已连接蓝色、连接中琥珀色闪烁、离线灰色）、可选的 CW2017 电量百分比，以及网络对时后的 24 小时制时钟（UTC+8，未对时显示 `--:--`）；底部状态行显示网络状态、行情错误和当前刷新间隔，刷新进行时状态文字左侧显示旋转指示。
- **设备内设置：**配网热点开关、五档亮度（背光 20–100%）、刷新间隔档位、自动息屏开关，以及 5–60 秒、每档 5 秒的息屏时间。
- **息屏省电：**无操作达到设定时间后关闭背光，行情降为每 60 秒轮询（手动刷新模式不轮询）；任意按键唤醒，唤醒的那一次按键不会执行原本操作；唤醒后恢复设定间隔并立即刷新。
- **网页配置：**查看设备与行情状态及持仓盈亏、今日盈亏两列，扫描／保存／清除 Wi-Fi，编辑自选股及每只股票的成本价与持仓手数，修改与设备菜单同步的设备设置。
- **Wi-Fi 漫游：**当前信号低于 -70 dBm 时，每 30 秒扫描同名 SSID；发现强至少 8 dB 且不弱于 -72 dBm 的 AP 时切换。
- **配置持久化：**Wi-Fi 凭证、自选股、每只股票的成本价与手数、刷新间隔、亮度、自动息屏和热点状态保存在 NVS。

## 按键操作

| 场景 | 上 / 下 | OK | 长按 OK |
| --- | --- | --- | --- |
| 行情列表 | 移动选中项 | 立即刷新行情 | 打开设置菜单 |
| 设置菜单 | 选择行；编辑态下调整数值 | 切换开关，或进入／结束编辑 | 关闭设置菜单 |
| 配网引导页 | — | — | 打开设置菜单 |
| 息屏状态 | 唤醒屏幕 | 唤醒屏幕 | 唤醒屏幕 |

设置菜单共五行：热点开关、屏幕亮度、刷新间隔、自动息屏、息屏时间。刷新间隔可在
手动、1、3、5、10、15、30、60、120、300 秒之间调整。息屏后的第一次按键只用于唤醒，
包括松手事件在内都不会触发原操作。

## 快速开始

1. 给设备上电。首次启动或清除 Wi-Fi 后，屏幕会显示配网引导卡，包含热点名称和 `http://192.168.4.1`。
2. 用手机或电脑连接 `FoloStock-XXXX` 热点。该热点是开放网络，使用 2.4 GHz 信道 6，最多允许 4 个客户端，无密码。
3. 打开 `http://192.168.4.1`，选择附近网络或手动填写 SSID，输入密码并保存；随后添加最多 8 个股票代码并设置刷新间隔，也可为每只股票填写成本价与持仓手数。
4. Wi-Fi 连接成功且自选股不为空后，屏幕自动进入行情列表并开始刷新。

热点默认开启。配网完成后可在网页或设备菜单中关闭；关闭后，仍可在同一局域网内通过
设备的局域网 IP 访问配置页。需要重新配网时，从设置菜单重新开启热点。

## 设置项

| 设置 | 范围与默认值 | 配置入口 |
| --- | --- | --- |
| 屏幕亮度 | 1–5 档，默认 3 档 | 设备菜单、网页 |
| 自动息屏 | 开／关，默认开 | 设备菜单、网页 |
| 息屏时间 | 5–60 秒，每档 5 秒，默认 30 秒 | 设备菜单、网页 |
| 配网热点 | 开／关，默认开 | 设备菜单、网页 |
| 刷新间隔 | 手动或 1/3/5/10/15/30/60/120/300 秒，默认 5 秒 | 设备菜单、网页 |
| 自选股 | 1–8 个代码 | 网页 |
| 成本价与持仓手数 | 每只股票可选；两项都填写后才显示盈亏与今日盈亏 | 网页 |

刷新间隔设为手动后，行情不会自动更新，按设备 OK 键刷新一次。网页上的亮度、自动息屏和
热点修改，只有在点击“保存设备设置”后才会写入设备。页面每 2 秒请求 `/api/status`，
用返回结果刷新状态卡和行情表。

## 股票代码

股票代码支持逗号、分号或空白分隔。可接受纯六位代码（`600519`）或带交易所前缀的
六位代码（`sh600519`、`sh000001`）。纯六位代码会自动推断交易所：`6`／`5` 开头为
沪市，`0`／`1`／`3` 开头为深市，`4`／`8` 开头为北交所。重复代码会被去掉，列表最多
保留 8 个。

指数必须显式写出交易所前缀。例如 `000001` 是深市股票，上证指数应写 `sh000001`。

## 本地 HTTP 接口

内置配置页由固件直接提供，使用以下接口：

| 方法与路径 | 用途 |
| --- | --- |
| `GET /api/status` | 设备、Wi-Fi、行情与配置快照 |
| `GET /api/config` | 当前自选股与设备设置 |
| `POST /api/config` | 保存 `codes` 与 `interval` |
| `POST /api/positions` | 保存每只股票的成本价与持仓手数 |
| `POST /api/settings` | 保存亮度、自动息屏与热点状态 |
| `GET /api/scan` | 扫描附近 2.4 GHz 网络 |
| `POST /api/wifi` | 保存 Wi-Fi 凭证并重连 |
| `POST /api/wifi/forget` | 清除已保存的 Wi-Fi |
| `POST /api/portal/close` | 收起设备上的配网引导页 |

## 行情与限制

- 行情来自新浪财经 `hq.sinajs.cn`。设备需要联网，且只支持 2.4 GHz Wi-Fi；ESP32-C3 不支持 5 GHz。
- 行情可能延迟，仅供查看参考。本固件不下单，也不构成投资建议。
- 持仓盈亏按（现价 − 成本价）× 持仓手数 × 100 股计算；今日盈亏按（现价 − 昨收）× 持仓手数 × 100 股计算。两者均不含手续费、税费和分红，仅供参考。
- 界面字体覆盖 GB2312 一级汉字和 23 个界面标点；盈亏行使用独立的 12px 精简字体。股票名称中的其他字符会显示为 `?`。
- 名称和代码过长时以省略号截断，以保证行内布局。
- 内置字体约占 770 KB Flash；开发板没有 PSRAM。
- 配网热点无密码。不使用时请关闭；也不要在共用电脑上长期打开配置页，浏览器会缓存表单内容，虽然设备不会回传已保存的 Wi-Fi 密码。

## 构建、测试与刷机

固件目标为 ESP-IDF 5.5.3 与 `esp32c3`。

```bash
source <ESP-IDF-v5.5.3-路径>/export.sh
idf.py set-target esp32c3
./tools/validate.sh --firmware
```

`validate.sh --firmware` 会在全新的临时目录中编译、校验固件布局，并把合并镜像写入
`build/FoloToy-AI-Passport-full.bin`，同时归档到 `build/firmware/<sha256>/`。
刷机时将该合并镜像写入 `0x0` 偏移。

合并镜像会重写整片固件区域，可能重置 NVS，导致 Wi-Fi 凭证、自选股和显示设置丢失。
需要保留已有 NVS 数据时，应在分区布局兼容的前提下改用分段 `idf.py flash`。刷写前
务必确认镜像文件和写入偏移。

主机侧检查：

```bash
./tools/validate.sh --static
```
